Safe Heritage School Website

About the Project

The Safe Heritage School Website is a simple and responsive school website developed to provide information about the school, its academic programmes, staff and activities.

The website was created as a school project using HTML, CSS and JavaScript. It is designed to give visitors an easy way to learn about Safe Heritage School and explore its different sections.

Features

* Home Page: Introduces the school, its mission, vision and core values.
* About Us: Provides information about the school’s history, background and staff members.
* Curriculum: Highlights the different educational levels offered by the school.
* School Gallery: Displays pictures of school activities, staff and events.
* * Contact Us: Provides the school’s contact information and a form for visitors to fill out.
* Responsive Design: Allows the website to adjust to different screen sizes.

Technologies Used

* HTML5 – Used to structure the website.
* CSS3 – Used for styling, layouts, Flexbox, Grid and responsiveness.
* JavaScript – Used for basic form validation and interactive features.
